WavePort documentation
======================

WavePort is a Python library for reading files produced by
`TICRA Tools <https://www.ticra.com/software/ticratools/>`_, an antenna analysis
suite. It exposes field coefficients as NumPy arrays for further analysis.

Start with installation and the tutorial, use the how-to guide for common
tasks, and consult the reference for API details.
